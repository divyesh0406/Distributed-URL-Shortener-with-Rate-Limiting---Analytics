# Frontend Deployment

This folder is a static Vercel frontend for the URL shortener API.

## Deploy on Vercel

1. Go to Vercel and create a new project.
2. Import the GitHub repository.
3. Set Root Directory to `frontend`.
4. Set Framework Preset to `Other`.
5. Leave Build Command empty.
6. Leave Output Directory as `.`.
7. Deploy.

The app defaults to:

```text
https://distributed-url-shortener-with-rate.onrender.com
```

After deploy, open the Vercel URL and run a shorten request from the form.
